# 제3자 저작물 현황

이 프로젝트는 **외부 저작물을 배포물에 포함하지 않습니다.**
아이콘·배경·폰트를 모두 자체 제작 또는 OS 기본 자원으로 처리했습니다.

## 현재 의존성

| 항목 | 처리 | 근거 |
|---|---|---|
| 아이콘 | **자체 제작** | `app/icons/index.tsx` — 직접 그린 24×24 stroke 도형 64종 |
| 폰트 | **OS 기본 폰트** | `styles/tokens.css` 의 `--ff`. 웹폰트 파일을 배포하지 않는다 |
| 이미지 | **없음** | Hero 배경은 CSS 그라디언트·패턴 (`styles/pages/home.css`) |
| 런타임 라이브러리 | react, react-dom (MIT) | 소스에 포함되지 않고 번들에만 들어간다 |
| 빌드 도구 | vite, typescript, @vitejs/plugin-react | 배포물에 포함되지 않는다 |

## 왜 이렇게 했나

### 아이콘

이전에는 `lucide-react`(ISC, 일부 Feather 파생분 MIT)를 썼습니다.
**두 라이선스 모두 공공기관의 상업·비상업 이용을 허용하므로 법적 문제는 없었습니다.**
다만 다음 이유로 자체 제작으로 바꿨습니다.

- 배포물에 제3자 저작권 고지문을 포함할 의무가 생긴다
- 납품·감사 단계에서 라이선스 확인 절차가 추가된다
- 아이콘 세트가 상위 버전에서 모양이 바뀌면 화면이 함께 흔들린다

교체 후 `package.json`의 런타임 의존성은 react, react-dom 둘만 남았습니다.

### 폰트

`fonts.googleapis.com` 을 호출하고 있었습니다.
폰트 자체(Noto Sans KR·Inter)는 OFL 이라 문제가 없지만, **CDN 을 호출하면 화면을
열 때마다 이용자 IP 가 외부 사업자에게 전송됩니다.** 국내 공공기관 점검에서
지적되는 항목이고, 독일에서는 같은 사유로 GDPR 위반 판결이 있었습니다.

OS 기본 폰트 스택으로 바꿔 외부 호출을 없앴습니다. 자체 호스팅도 가능하지만,
웹폰트 파일을 배포물에 넣으면 다시 OFL 고지 의무가 생깁니다.

### 이미지

Hero 배경에 Unsplash 사진 4장을 핫링크하고 있었습니다.
Unsplash 라이선스는 관대하지만 다음 위험이 남습니다.

- **사진 속 인물·상표·건물에 대한 권리는 별개다** (모델 릴리스 없음)
- 외부 도메인 의존이라 망분리·차단 환경에서 배경이 깨진다
- 이미지를 받을 때 이용자 IP 가 외부로 전송된다

CSS 그라디언트와 반복 패턴으로 4종 배경(`.hero__bg--quality|data|briefing|report`)을
만들어 대체했습니다.

## 외부로 나가는 요청

배포물에서 외부 도메인으로 나가는 **자동 요청은 없습니다.**
확인 방법:

```js
performance.getEntriesByType('resource')
  .map(r => r.name)
  .filter(n => !n.startsWith(location.origin));
// => []
```

아래는 이용자가 직접 눌렀을 때만 이동하는 **공식 기관 링크**입니다.

| 링크 | 대상 |
|---|---|
| `oilreport.or.kr` | 석유제품 수급보고시스템 |
| `kpetro.or.kr/smart` | 오일톡톡 |
| `epeople.go.kr` | 국민신문고 |
| `ncp.clean.go.kr` | 국민권익위원회 부패·공익신고 |
| `opinet.co.kr` | 한국석유공사 유가정보 |

## 아이콘을 추가할 때

`app/icons/index.tsx` 에 직접 그려 넣습니다. 외부에서 path 를 복사해 오지 않습니다.

- 24×24 격자, `fill="none"`, `stroke="currentColor"`
- 기본 굵기 1.8, 끝·꼭짓점 round
- 장식용은 `aria-hidden="true"`, 의미가 있으면 `aria-label` 을 넘긴다
